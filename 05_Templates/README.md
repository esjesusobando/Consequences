# Templates

> Enforce structure. Always use templates.

## Available

| Template | Use For |
|----------|---------|
| [[daily]] | Daily notes |
| [[session]] | Session logs |
| [[decision]] | ADRs |
| [[learning]] | Gotchas & patterns |
| [[postmortem]] | Incident reports |
| [[reference]] | External knowledge |
| [[clipping]] | External captures (articles, essays) |

## Properties (Steph Ango style)

| Property | Purpose |
|----------|---------|
| `categories` | Plural category tags for Bases/filtering |
| `created` / `updated` | YYYY-MM-DD lifecycle dates |
| `rating` | 1–7 score for knowledge notes |
| `source` | Origin URL for references |
