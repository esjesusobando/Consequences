# SKILL: Legacy Archive

**Área:** 09_Legacy_Archive
**Estado:** Archive — Skills obsoletas o deprecadas
**Versión:** v2.0 Consequences

## Propósito

Archivo de skills que fueron parte del sistema en versiones anteriores (v1.x) y que han sido reemplazadas, fusionadas con otras áreas, o deprecadas en v2.0.

## Contenido

Skills archivadas de versiones anteriores al sistema v2.0 Consequences.
No se deben usar activamente — existen como referencia histórica.

## Notas

- No activar estas skills en producción
- Si se necesita recuperar una skill archivada, moverla al área funcional correspondiente
- Ver `01_Personal_Os/01_Core/02_Tools/02_Skills/` para las 9 áreas activas
