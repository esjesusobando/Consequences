# 04_Contexto — Contexto de Proyecto para Marketing Agents

**Versión:** v4.9 | **Fecha:** 2026-05-26

Carpeta que almacena el contexto del proyecto activo para alimentar a los agentes de Growth y Marketing con informacion personalizada y alineada al negocio.

---

## Proposito

Los agentes de Growth (03_Growth/) necesitan contexto para generar contenido relevante. Esta carpeta centraliza esa informacion.

---

## Estructura esperada

```
04_Contexto/
├── LEEME.md                    # Instrucciones de uso
├── proyecto.md                 # Descripcion del proyecto activo
├── audiencia.md                # Perfil de audiencia objetivo
├── estrategia.md               # Estrategia de contenido
└── kpis.md                     # KPIs y metricas objetivo
```

---

## Como usar

1. Completar los archivos de contexto con la informacion del proyecto activo
2. Los agentes de `03_Growth/` leen este contexto antes de generar contenido
3. Actualizar cuando cambie el proyecto o la estrategia
