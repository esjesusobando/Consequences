## Prompts Extracted from Content

### Prompt 1: Meta Prompting

```
I have this prompt I use frequently: [INSERT PROMPT]
I want you to improve it. Ask me whatever questions you need to understand the context,
then return the improved prompt with explanations for each change.
```

### Prompt 2: Improve Context

```
I'm working on [DESCRIBE YOUR PROJECT/TASK].
I have access to these tools: [LIST TOOLS].
What context should I put in the context window to get better AI results?
```

### Prompt 3: Identify Use Cases

```
Analyze my current workflow: [DESCRIBE YOUR WORK].
What repetitive, high-impact tasks could I automate with AI?
Suggest the top 5 priority use cases using the 60-30-10 rule.
```

### Prompt 4: AI Team Strategy

```
I have a team of [NUMBER] people.
I want to implement AI using the TRIAGE → EXPERIMENT → AUTOMATE → MEASURE strategy.
Create an implementation plan with timeline, deliverables, and metrics for each phase.
```

### Prompt 5: Customize AI

```
Create custom instructions for an AI assistant that:
- Is [PERSONALITY: creative, analytical, etc.]
- Writes in style [STYLE: technical, conversational, etc.]
- Knows my background: [BACKGROUND]
- Focuses on [MAIN OBJECTIVE]
```
