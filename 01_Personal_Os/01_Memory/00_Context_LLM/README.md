# 00_Context_LLM — Contexto para LLMs

## Qué hay aquí
Documentos y referencias que los LLMs leen para entender tu contexto.

## Cuándo usarlo
- Cuando necesitas que el LLM conozca tu proyecto
- Para onboarding de nuevos agentes
- Para decisions que requieren contexto histórico

## Cómo acceder
- Leer `index.md` primero
- Luego explorar subcarpetas relevantes

## QUÉ NO HACER
- ❌ No meter archivos de código aquí
- ❌ No duplicar información de otros folders
