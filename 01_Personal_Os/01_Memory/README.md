# 01_Memory — Memoria Persistente

## Qué hay aquí
Memoria del OS que sobrevive sesiones. Notas de contexto, decisiones pasadas, learnings.

## Cuándo usarlo
- Antes de empezar sesión: `engram_mem_context`
- Buscar algo específico: `engram_mem_search "keyword"`
- Después de decisión importante: `engram_mem_save`

## Cómo acceder
- Via Engram MCP tools
- Via scripts: `python memory_search.py "query"`

## QUÉ NO HACER
- ❌ No editar manualmente archivos de Engram
- ❌ No borrar observations sin razón clara
- ❌ No guardar información temporal aquí
