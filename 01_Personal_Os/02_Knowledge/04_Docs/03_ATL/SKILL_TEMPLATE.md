### Deliverable 2: Visualización HTML Obligatoria

Según la nueva regla de PersonalOS v4.9, **todo resultado debe incluir un archivo HTML de visualización**:
- **Archivo**: `resultado.html` (o nombre descriptivo según contexto)
- **Ubicación**: Mismo directorio que el resultado principal
- **Contenido**: 
  - Para resultados genéricos: resumen visual, métricas clave, diagramas de flujo
  - Para contenido social/marketing: simulación exacta de interfaz de Instagram (móvil y escritorio)
  - Para análisis técnicos: gráficos interactivos, árboles de dependencias, visualizaciones de datos
- **Propósito**: Permitir revisión rápida y atractiva de resultados sin necesidad de leer documentación extensa
