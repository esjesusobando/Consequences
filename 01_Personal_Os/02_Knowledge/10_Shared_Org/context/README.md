# Contexto Compartido — Shared Org

> Archivos de contexto que definen la organización.
> Se cargan como base para todos los agentes del equipo.

---

## Archivos

| Archivo           | Propósito                                      | Estado      |
| ----------------- | ---------------------------------------------- | ----------- |
| `organizacion.md` | Descripción de la organización, misión, visión | 📝 Pendiente |
| `equipos.md`      | Equipos, roles, responsabilidades              | 📝 Pendiente |
| `herramientas.md` | Stack tecnológico y herramientas               | 📝 Pendiente |
| `proyectos.md`    | Proyectos activos y estado                     | 📝 Pendiente |

---

## Cómo Usar

1. Cada equipo completa los archivos de contexto que le corresponden
2. Los agentes cargan `organizacion.md` como contexto base al iniciar
3. Los contextos se actualizan trimestralmente (o cuando hay cambios significativos)
