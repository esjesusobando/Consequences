## 🧠 Core Thesis

Tutorial completo de configuración de Claude Code aplicado al marketing. Explica cómo instalar, configurar y usar Claude Code desde la terminal para automatizar tareas de marketing: creación de contenido, análisis, investigación y generación de activos. El enfoque es práctico y orientado a que profesionales de marketing sin experiencia técnica puedan usar Claude Code como herramienta de trabajo diaria.

---

## ⚡ Key Concepts

### 1. Setup Inicial
- Instalación vía terminal (macOS/Windows/Linux)
- Autenticación con cuenta Anthropic
- Configuración de VS Code como editor
- Permisos y seguridad del directorio de trabajo

### 2. Claude Code para Marketing
- Claude Code no requiere saber programar
- Se opera por comandos en lenguaje natural
- Skills de marketing: tono de voz, guías de marca, estructura de contenido
- Contexto persistente: CLAUDE.md para recordatorio de proyectos

### 3. Flujos de Trabajo Clave
- Investigación de mercado y competencia
- Drafting de contenido (blog, email, redes sociales)
- Generación de assets visuales
- Automatización de tareas repetitivas
