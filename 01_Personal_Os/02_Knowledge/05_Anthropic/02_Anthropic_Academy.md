## 📌 ¿Qué es?

El **Anthropic Academy** (anteriormente /learn) es el hub central de recursos educativos de Anthropic. Agrupa documentación, guías y cursos sobre cómo usar Claude y su ecosistema en distintos contextos: desarrollo, empresa y uso personal.

Estructura del hub:

### 1. Build with Claude
> https://www.anthropic.com/learn/build-with-claude

Guías y documentación para desarrolladores. Incluye:
- API guides y best practices
- Model Context Protocol (MCP)
- Integraciones técnicas
- Prompt engineering avanzado

### 2. Claude for Work
> https://www.anthropic.com/learn/claude-for-work

Implementación de Claude en organizaciones:
- Enterprise deployment best practices
- Team productivity con Claude
- Casos de uso empresarial
- Seguridad y compliance

### 3. Claude for Personal
> https://www.anthropic.com/learn/claude-for-you

Uso individual de Claude:
- Proyectos personales
- Daily tasks optimization
- Creative workflows
