# 03_Learning — Aprendizaje Auto-Generado

## Qué hay aquí
Patterns, metrics, telemetry. Generado automáticamente por el OS.

## Cuándo usarlo
- Para ver qué ha aprendido el OS
- Para revisar métricas de performance
- Para entender qué está funcionando y qué no

## Cómo acceder
- `01_Auto_Improvement/` — patterns y learnings
- `04_Telemetry/` — métricas y dashboards
- `02_Skill_Performance/` — performance por skill

## QUÉ NO HACER
- ❌ No editar learnings.json manualmente
- ❌ No borrar telemetry sin backup
- ❌ No asumir que un learning es válido sin verificar
