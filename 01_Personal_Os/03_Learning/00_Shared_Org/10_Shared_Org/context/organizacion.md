# Organización — Contexto Compartido

> Descripción base de la organización.
> *Actualizado: 2026-06-27*

---

## Misión

Transformar el conocimiento organizacional en un activo vivo, LLM-agnóstico, que se acumula y se potencia con cada proyecto. El Capital Token captura lo que el equipo sabe hacer para que ningún aprendizaje se pierda y cada nuevo proyecto se apoye en el anterior.

## Visión

Ser el sistema operativo de conocimiento que permite a un equipo reducido operar con la eficiencia de una organización mucho más grande — donde el onboarding toma horas, no semanas; donde las decisiones pasadas informan las futuras, y donde el conocimiento institucional es accesible para cualquier miembro del equipo o agente de IA en cualquier momento.
