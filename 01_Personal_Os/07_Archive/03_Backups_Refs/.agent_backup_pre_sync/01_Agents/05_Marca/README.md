# 05_Marca — Brand Assets y Voz de Marca

**Versión:** v3.3 | **Fecha:** 2026-04-29

Repositorio de assets de marca y guias de voz para garantizar consistencia en todo el contenido generado por los agentes.

---

## Proposito

Centraliza la identidad de marca del proyecto activo — tono, voz, paleta, tipografia, guidelines — para que los agentes de Growth generen contenido 100% on-brand.

---

## Estructura esperada

```
05_Marca/
├── LEEME.md                    # Instrucciones de uso
├── voz.md                      # Tono y voz de marca
├── visual.md                   # Guia visual (colores, tipografia)
├── mensajes_clave.md           # Mensajes y propuesta de valor
└── ejemplos/                   # Ejemplos de contenido aprobado
```
