## 🛠️ gentle-pi — Setup (Gentleman harness para Pi)

gentle-pi es un plugin que corre sobre `@earendil-works/pi-coding-agent`. No es un CLI standalone.

```bash
# Install pnpm
npm install -g pnpm

# Install pi + gentle-pi
pnpm install -g @earendil-works/pi-coding-agent
pnpm install -g gentle-pi

# Run (desde directorio con permisos de escritura)
cd Think_Different
pi --provider minimax --model MiniMax-M2.7
```

Paquetes instalados:
- `pnpm 11.1.2` → `AppData\Local\pnpm`
- `@earendil-works/pi-coding-agent 0.74.0` → pnpm global store
- `gentle-pi 0.3.2` → npm global `AppData\Roaming\npm`
- `gentle-engram 0.1.4` → pnpm global store
- `yt-dlp 2026.03.17` → `Python\Python314\Scripts`
- `youtube-transcript-api 1.2.4` → pip

Variables necesarias (ya en `.bashrc`):
```
MINIMAX_API_KEY, MINIMAX_GROUP_ID, PNPM_HOME, PI_CODING_AGENT_DIR
```

Para transcripción YouTube:
```python
from youtube_transcript_api import YouTubeTranscriptApi
YouTubeTranscriptApi.list_transcripts("VIDEO_ID")
```
