# 🦾 Skill 32: Batch Doc Processor Elite

## Overview
Esta Skill permite realizar extracciones masivas de información de directorios enteros. Utiliza el motor `26_Batch_Parser.py` para iterar sobre archivos compatibles y generar un reporte consolidado en Markdown.

## 🚀 Capacidades
- **Escaneo Recursivo:** Puede navegar por subcarpetas de forma automática.
- **Consolidación:** Agrupa la salida de múltiples archivos en un solo documento de conocimiento.
- **Soporte Universal:** Compatible con todos los formatos de la **Skill 31** (PDF, Office, PSD, TIFF).

## 🛠️ Uso
Para procesar un directorio:
`python 06_ENGINE/26_Batch_Parser.py <directory_path> --output <output_file.md> --recursive`
