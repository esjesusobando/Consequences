## Credenciales necesarias para TubeMaster

```dotenv
GOOGLE_CLIENT_ID=tu-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=tu-client-secret
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=generate-a-long-random-secret
```

**Pasos:**
1. Google Cloud Console → APIs y servicios → Biblioteca → YouTube Data API v3 → Habilitar
2. APIs y servicios → Credenciales → Crear credenciales → ID de cliente OAuth → Aplicación web
3. Agregar URIs: `http://localhost:3000` y `http://127.0.0.1:8787`
4. Copiar Client ID y Client Secret
