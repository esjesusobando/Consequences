## 🛠️ TÉCNICAS APRENDIDAS

### Windows Rename Permission Issues

**Problema:** `PermissionError: [WinError 5] Acceso denegado` al intentar renombrar carpetas en Windows.

**Soluciones aplicadas (en orden de efectividad):**

1. **PowerShell con Rename-Item** — Funciona cuando mv/bash fallan
   ```powershell
   Rename-Item -Path 'old_name' -NewName 'new_name' -Force
   ```

2. **Rename vía two-step** — Cuando fuente y destino son "iguales" (case only):
   ```powershell
   Rename-Item -Path 'OldName' -NewName 'TempName'
   Rename-Item -Path 'TempName' -NewName 'NewName'
   ```

3. **Git rm --cached** — Para desatachar tracking antes de rename:
   ```bash
   git rm --cached path/to/folder
   ```

4. **Copy + Delete** — Último recurso:
   ```bash
   cp -r source/. dest/ && rm -rf source
   ```
