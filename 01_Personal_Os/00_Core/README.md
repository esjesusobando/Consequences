# 00_Core — Núcleo del OS

## Qué hay aquí
Rules, workflows, skills. Archivos críticos del sistema.

## Cuándo usarlo
- Para entender las reglas del OS
- Para modificar workflows
- Para agregar nuevos skills

## Cómo acceder
- `01_Rules/` — reglas del sistema
- `00_Workflows/` — workflows y rituales
- `02_Tools/` — skills y agentes

## QUÉ NO HACER
- ❌ No modificar rules sin validación
- ❌ No agregar skills sin testing
- ❌ No tocar archivos marcados como críticos
