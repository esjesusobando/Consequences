# 13_Seo_Sota_Master — References

> Documentación de referencia adicional para esta skill de SEO SOTA Master.

## Propósito

Esta carpeta contiene guías, schemas, templates y recursos complementarios para la ejecución de auditorías SEO, estrategias de contenido, y SEO programático.

## Estructura

- `schemas/` — Ejemplos de schema markup (JSON-LD) para distintos tipos de contenido
- `templates/` — Templates de reportes SEO y estrategias
- `scripts/` — Scripts auxiliares para análisis SEO
- `cheatsheets/` — Guías rápidas de herramientas y métricas

## Uso

Cargar los archivos de referencia cuando se necesite:

- Un schema específico (Product, FAQ, Article, LocalBusiness)
- Un template de reporte para presentar a stakeholders
- Una guía de herramienta SEO (Ahrefs, SEMrush, Search Console)

## Mantenimiento

- Agregar nuevos schemas a `schemas/` cuando se descubran patrones útiles
- Actualizar templates cuando cambien formatos de reporte
- Mantener cheatsheets actualizadas con versiones de herramientas
