## Principios de Agentic Engineering

1. **Estructura sobre improvisación** — Los archivos canónicos son el contrato
2. **El humano decide, el agente ejecuta** — Human-in-the-loop no es opcional
3. **Contexto explícito** — Todo lo que el agente necesita saber está en los archivos
4. **Anti-alucinación por diseño** — Las exclusiones explícitas capan comportamientos no deseados
