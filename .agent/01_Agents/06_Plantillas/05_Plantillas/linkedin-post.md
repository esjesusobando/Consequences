## Estructura del Post

### Formato Estándar

```
[HEADER — Takeaway principal, máximo 1-2 líneas]

[CONTEXTO — 2-4 líneas que establecen el escenario]

[CUERPO — 3-5 párrafos con insight + ejemplo/concrete]

[CIERRE — Cierre memorable o pregunta para engagement]

#Hashtags #Relevantes #AlPúblico
```

### Formato Thread (para temas complejos)

```
[HILO: Tema del thread]

[POST 1 — Hook + Contexto]
[POST 2 — Punto 1 con ejemplo]
[POST 3 — Punto 2 con ejemplo]
[POST 4 — Punto 3 con ejemplo]
[POST 5 — Cierre + CTA]
```

## Guidelines por Tipo

### Posts de Tutorial
- **Tono:** Práctico, step-by-step
- **Estructura:** Lista numerada, no párrafos largos
- **Engagement:** "Share with someone who needs this"

### Posts de Reflection
- **Tono:** Personal pero no navel-gazing
- **Estructura:** Narrative arc (problema → solución → insight)
- **Engagement:** Pregunta al final

### Posts de Opinion
- **Tono:** Asertivo, no apologético
- **Estructura:** Claim → Evidence → Implication
- **Engagement:** "Agree? Disagree?"

### Posts de Stats/Research
- **Tono:** Neutral, factual
- **Estructura:** Hook stat → Context → Implication
- **Engagement:** "What do you think?"

## Quality Checklist

Antes de publicar:
- [ ] ¿El header es un takeaway claro, no clickbait?
- [ ] ¿El post es helpful o solo buscando likes?
- [ ] ¿El tono es auténtico o forzado?
- [ ] ¿Hay claim sin evidencia?
- [ ] ¿Los hashtags son relevantes (máx 5)?
- [ ] ¿El post tiene longitud adecuada (150-300 palabras)?
- [ ] ¿Tiene al menos un "hook" visual (si aplica)?

## Ejemplo Real

```markdown
Me tomó 3 semanas entender por qué mi agent de Claude Code seguía fallando en el mismo paso.

El problema: estaba usando el agent para TODO. Cuando debería haberlo usado solo para las partes que realmente necesitan model reasoning.

Aquí va lo que nadie te dice:

→ Los agents no son iguales a un developer junior
→ El context window tiene límites reales
→ A veces lo más productivo es hacer algo manualmente

Lesson: Los agents son compañeros, no reemplazos.

¿Alguno pasó por algo similar?
```

## Frecuencia Recomendada

- **3-5 posts/semana** (no más, para mantener calidad)
- **1-2 threads/semana**
- **1 announcement/mes** (máximo)
- **Mix:** 40% tutorial, 30% reflection, 20% engagement, 10% personal
