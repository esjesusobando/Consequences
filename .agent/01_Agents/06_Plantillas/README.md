# 06_Plantillas — Templates Reutilizables

**Versión:** v4.9 | **Fecha:** 2026-05-29

Coleccion de plantillas generales reutilizables para los agentes del sistema — desde estructura de posts hasta formatos de documentos.

---

## Proposito

Evitar que los agentes generen desde cero cada vez. Las plantillas aceleran la generacion y garantizan consistencia de formato.

---

## Estructura esperada

```
06_Plantillas/
├── LEEME.md                        # Instrucciones de uso
├── post_linkedin.md                # Template post LinkedIn
├── hilo_twitter.md                 # Template hilo Twitter/X
├── email_newsletter.md             # Template email marketing
├── brief_video.md                  # Brief para videos YouTube
└── estructura_carrusel.md          # Estructura de carrusel
```

---

## Como agregar una plantilla nueva

1. Crear archivo `nombre_descriptivo.md` en esta carpeta
2. Incluir: descripcion, variables a reemplazar, ejemplo completo
3. Referenciar desde el agente que la usa
