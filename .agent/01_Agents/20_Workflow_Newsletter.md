# Workflow: Newsletter — De Curación a Envío

**Agentes involucrados:** Estratega → Creador → Analista
**Ciclo:** Semanal / Quincenal

---

## Flujo

```
SEMANA (temas definidos por el Estratega)
  │
  ▼
[ESTRATEGA] → Brief de newsletter (tema principal, secciones)
  │
  ▼
[CREADOR] → Newsletter completa (asunto, preview, cuerpo)
  │
  ▼
REVISIÓN HUMANA ✅
  │
  ▼
ENVÍO
  │
  ▼
[ANALISTA] → Open rate, CTR, conversiones
```

---

## Paso a Paso

### 1. Disparador
*"Prepará la newsletter de esta semana"*

### 2. Estratega
```markdown
@Marketing_Estratega
"Definí el contenido para la newsletter de [fecha].
Tema principal: [X].
Secciones: [noticias, tutorial, recomendación, etc.]."
```

### 3. Creador
```markdown
@Marketing_Creador
"Redactá la newsletter siguiendo este brief.
Usá plantilla newsletter.md.
Incluí: asunto (subject line), preview text, cuerpo con storytelling, CTA."
```

### 4. Checklist de Revisión
- [ ] Subject line genera curiosidad/urgencia?
- [ ] Preview text complementa el asunto?
- [ ] Escaneable (subtítulos, bullets)?
- [ ] CTA único y claro?
- [ ] Links funcionan?
