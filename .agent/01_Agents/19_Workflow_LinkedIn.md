# Workflow: LinkedIn — Post de Autoridad

**Agentes involucrados:** Estratega → Creador → Analista
**Ciclo:** Completo

---

## Flujo

```
TEMA (tú / estratega)
  │
  ▼
[ESTRATEGA] → Brief de post (ángulo, audiencia, tono)
  │
  ▼
[CREADOR] → Post completo (hook → story → insight → CTA)
  │
  ▼
REVISIÓN HUMANA ✅
  │
  ▼
PUBLICACIÓN
  │
  ▼
[ANALISTA] → Engagement report + recommendations
```

---

## Paso a Paso

### 1. Disparador
*"Quiero postear sobre [tema] en LinkedIn"*

### 2. Estratega
```markdown
@Marketing_Estratega
"Generá un brief para LinkedIn sobre [tema].
Formato: post personal / artículo / carrusel.
Objetivo: autoridad / leads / engagement."
```

### 3. Creador
```markdown
@Marketing_Creador
"Escribí el post de LinkedIn siguiendo este brief.
Usá la plantilla linkedin-post.md.
Estructura: hook → problema → solución/historia → insight → CTA."
```

### 4. Checklist de Revisión
- [ ] Hook en primeras 2 líneas (se corta en feed)?
- [ ] Párrafos cortos (máx 3 líneas)?
- [ ] Tono profesional pero cercano?
- [ ] CTA específico?
- [ ] Hashtags (3-5 relevantes)?
