# Skills vs Projects — La Diferencia que importa

---

## Skills (Automatización)

Son **instrucciones fijas** para una tarea específica. Se ejecutan SIEMPRE igual.

**Qué convertir en Skill:**
- Reportes semanales/recurrentes
- Posts de LinkedIn con estructura fija
- Meeting notes → action items
- Code review templates
- Cualquier tarea administrativa que hagas semanalmente

**Cómo crear:**
1. Ejecuta el proceso completo con Claude
2. Dile: "Convierte esto en una skill"
3. Claude la guarda automáticamente

**Dónde conseguir skills pre-hechas:**
- SkillMP (marketplace comunitario)
- GitHub (skills open source)
- La comunidad de Claude

## ⚠️ Projects (Peligro de Fragmentación)

**NO son carpetas organizadoras.** Projects tienen memoria SEPARADA.

**Problema:**
| Situación | Resultado |
|-----------|-----------|
| Entrenas a Claude en chat general sobre tu marca | ✅ Claude te conoce |
| Abres un Project nuevo | ❌ Claude NO te conoce |
| Trabajas en Project #1 | ❌ Project #2 no sabe nada |
| Memorias personales | ❌ No disponibles en Projects |

**Síntomas de fragmentación:**
- Claude actúa como si nunca te hubiera conocido
- Tienes que re-explicar tu tono, identidad, preferencias
- Todo el conocimiento acumulado en memoria general no está accesible

**Regla práctica:**
- Máximo 1-2 Projects, SOLO si necesitas aislamiento deliberado
- Para organización: usa chats normales con nombres claros
- Si ya tienes un Project: puedes mover cualquier chat FUERA del Project (Settings → toggle out)
