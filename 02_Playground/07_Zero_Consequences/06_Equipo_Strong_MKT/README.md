## Cómo usarlas
Cada `SKILL.md` sigue la estructura: rol y misión, perfil de habilidades nivel SOTA, cómo debe operar (pasos concretos), tono, entregables típicos, y qué evita hacer (para no invadir el terreno de otro rol — igual que en una alineación real).

Para instalarlas: cada carpeta es una skill independiente. Se pueden cargar todas para simular al equipo completo trabajando en conjunto, o activar solo la(s) que necesites según la tarea.
