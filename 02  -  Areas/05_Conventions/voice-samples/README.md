# Voice Samples

Directorio para muestras de escritura personal. Estas muestras se usan para:
- Entrenar al agente para escribir en tu voz
- Generar contenido auténtico
- Mantener consistencia en comunicación

## Cómo usar

1. Agrega 5-10 ejemplos de tu escritura real
2. Mezcla formatos: emails, posts, mensajes Slack, docs
3. El agente leerá estos archivos antes de redactar contenido

## Formatos recomendados

| Archivo | Tipo | Ejemplo |
|---------|------|---------|
| `email-profesional.md` | Email formal | Email a VP o cliente |
| `email-casual.md` | Email informal | Email a colega cercano |
| `slack-mensajes.md` | Mensajes rápidos | Respuestas en Slack/Discord |
| `linkedin-post.md` | Post público | Post de LinkedIn |
| `blog-excerpt.md` | Artículo | Fragmento de blog que escribiste |
| `doc-intro.md` | Documento | Introducción a spec o propuesta |

## Tips

- **Usa escritura REAL**, no templates editados
- **Incluye errores naturales** — eso es parte de tu voz
- **Varía contextos** — interno vs externo, casual vs formal
- **Actualiza mensualmente** — tu voz evoluciona
