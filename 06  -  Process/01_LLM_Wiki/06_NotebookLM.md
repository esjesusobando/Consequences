# NotebookLM

## Overview
Herramienta de research de Google para digest de contenido. Permite cargar fuentes y hacer preguntas sobre ellas.

## Key Features
- **Source Upload**: Carga PDFs, URLs, YouTube, text
- **Digest**: Resúmenes automáticos de fuentes
- **Q&A**: Preguntas y respuestas sobre el contenido
- **Audio**: Genera podcasts de resúmenes

## Limitations (vs AI Research OS)
- **No ownership**: No controlas los datos
- **No personalization**: No puedes customizar
- **No agent native**: No se integra con agentes
- **Browser based**: No es suitable para coding tasks

## Use Case in AI Research OS
- Fuente de research profundo
- Digest de artículos largos y papers
- Se integra como fuente en el deep research algorithm
- Alternativa a RAG para investigación personal

## Setup
- Ir a notebooklm.google.com
- Crear notebook
- Agregar fuentes (URLs, PDFs, YouTube)
- Hacer preguntas y generar resúmenes
