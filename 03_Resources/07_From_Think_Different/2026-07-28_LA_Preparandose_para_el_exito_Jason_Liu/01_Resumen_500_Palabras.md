## ES (Español)

Jason Liu, ingeniero en OpenAI, comparte su flujo de trabajo diario usando Codex como su asistente principal para todo, no solo programar.

**Mensaje central**: La clave no es usar más tokens, sino usar los que ya tienes de forma inteligente.

### Lo que aprendimos

1. **Compaction funciona mejor de lo que crees.** Las conversaciones largas no degradan. Jason tiene hilos de 5 semanas con 400 sub-agentes que siguen funcionando y saben exactamente qué hacer.
2. **Appshots es la feature más subestimada.** Screenshot + accessibility tree = contexto estructurado. Convierte 4 tool calls en UNO.
3. **Computer Use como AGI laboral.** Controlar cualquier aplicación por detrás del escritorio sin tomar el control visual. Incluso desde el teléfono con laptop cerrada.
4. **Skills como bloques de construcción.** Cada skill son unos pocos archivos y un script. Empaquetar en plugins crea una biblioteca reutilizable.
5. **Memory Vault + Automations = Equipo IA.** Tu vault de memoria se convierte en la fuente de verdad. Las automations despiertan hilos periódicamente.
6. **El plugin hero mindset.** Construye skills que beneficien a tu equipo entero, no solo a ti.

### Insight clave para Think_Different OS
La compounding de conocimiento via Engram + skills personalizados es la ventaja competitiva real — no solo tener AI, sino tener AI que recuerda y actúa por ti.

## EN (English)

Jason Liu, an engineer at OpenAI, shares his daily workflow using Codex as his primary assistant for everything, not just coding.

**Core message**: It's not about using more tokens, it's about using your tokens intelligently.

### Key Takeaways

1. **Compaction works better than you think.** Long conversations don't degrade. Pin and rename threads instead of starting new ones.
2. **Appshots is the most undervalued feature.** Screenshot + accessibility tree gives structured context. 4x efficiency gain.
3. **Computer Use feels like workplace AGI.** Control any application behind the scenes. Locked use lets you trigger commands from phone with laptop closed.
4. **Skills are building blocks.** Each skill is a few files + a script. Package into plugins for a reusable library.
5. **Memory Vault + Automations = AI Teammates.** Memory vault becomes source of truth. Automations wake threads periodically.
6. **Plugin Hero Mindset.** Build everything to benefit your team. When colleagues use what you built, that is the biggest signal of impact.

### Insight for Think_Different OS
Jason: "Invested in my personal memory" and now doesn't need to remember meetings because his vault does the work. Knowledge compounding via Engram + custom skills is the real competitive edge.
