# 03_Contexto

> Contexto del proyecto, marca y configuración del sistema de Marketing Agents.

**Ubicación:** `.agent/01_Agents/03_Contexto/`

## Contenido

Aquí se almacena todo el contexto del proyecto:
- Objetivos y metas del proyecto
- Estrategia de contenido
- Audiencias objetivo
- KPIs y métricas
- Información del negocio

## Uso

Este folder alimenta a los agentes con el contexto necesario para generar contenido personalizado y alineado con los objetivos del proyecto.
