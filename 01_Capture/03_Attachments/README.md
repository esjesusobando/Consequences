# Attachments

> Central folder for media assets: images, PDFs, audio, video.

## Rules

- **One place for everything** — configured in `app.json` (`attachmentFolderPath: "09_Attachments"`)
- **Link, don't copy** — reference assets via wikilinks from notes
- **Never organize here** — this folder is storage, not structure
- **No README sprawl** — only this index; media files live flat or in dated subfolders
