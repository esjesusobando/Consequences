## Taller: Preparándose para el Éxito

---

## Insights para ~/Knowledge

- **Compaction > Thread Splitting.** The old advice "start a new thread after 20 messages" is obsolete. Compaction makes long threads viable. Pin and rename instead of starting new ones.
- **Skills self-improve.** A skill shared with the team needs to be battle-tested for months. Personal skills can yolo one-shot and correct on the fly. Team skills = quality gates. Personal skills = speed gates.
- **Appshots changes the automation paradigm.** Before: screenshot → OCR → parse → act (4 tool calls). After: screenshot with accessibility tree → 1 function call. 4x efficiency gain.
- **Memory Vault = Context Superpower.** The model can draft responses, open Chrome tabs for email replies, and manage meetings — all from memory vault lookups. The vault becomes a living teammate.
- **Ultra Goal with file-based plan is a game-changer.** When the plan is in a file that gets edited mid-run, you get a self-adjusting system. The model can expand scope, add constraints, track progress without restarting a session.
- **"Write like me" is possible at scale.** Feed 6 months of emails + Slack → get a style guide → apply to all outgoing messages. Eliminates the "AI tone" problem for personal communication.

## Aprendizajes No Obvios

1. **The "55 model is reluctant" pattern.** Jason notes the 55 models are cautious about destructive actions. Use "auto review" + "ask me every time" permissions for agentic work. Trust the model but gate the actions.
2. **Monorepo per person, not per project.** Jason manages 16 demo repos from a single monorepo sidebar. The `.agentsmd` directive routes where code lands. Simpler than project-per-folder.
3. **"The AI becomes your manager" pattern.** As you invest in skills and memory, you go from IC → manager of AI agents. The pinned thread becomes the manager, sub-threads become ICs. This is where the puck is going.
