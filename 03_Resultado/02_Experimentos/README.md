# 02_Experimentos

Esta carpeta contiene experimentos, ejercicios, pruebas prácticas y recursos de aprendizaje activo relacionados con el sistema Think Different PersonalOS.

## Subcarpetas:
- **00_Recursos_Varios**: Recursos diversos y materiales varios
- **00_World_OIM**: Proyecto OIM Website con su historial completo (incluye submodule)
- **01_Frontend_Slides_Exercise**: Ejercicios de presentación y slides frontend
- **02_Huashu_Design_Exercise**: Ejercicios de diseño siguiendo la metodología Huashu
- **04_Sessions**: Grabaciones y documentación de sesiones de trabajo
- **05_Imagenes_Finales**: Imágenes finales y resultados de procesos de diseño
- **06_AI_News_Weekly**: Recopilaciones semanales de noticias de IA
- **07_Clinica_Infantil**: Proyecto de clínica infantil
