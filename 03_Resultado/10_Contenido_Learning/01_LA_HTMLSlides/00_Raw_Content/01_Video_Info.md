## Resumen del Contenido
Tutorial completo sobre cómo usar HTMLSlides - una skill gratuita y open source para crear presentaciones HTML con IA (Claude Code, Copilot, Gemini CLI, Cursor, Windsurf).

### Características Principales:
- Single HTML file (todo inline, sin dependencias)
- 17 visual themes (5 Pro + 12 Vibe)
- Dual-display presenter mode (presentador + audiencia)
- AI-generated speaker notes
- Convierte PowerPoint, reveal.js, Marp, Google Slides, artículos
- Modo Pro (componentes estructurados) vs Vibe (temas creativos)

### Flujo de Trabajo:
1. Instalar skill desde GitHub
2. Describir presentación en inglés
3. Elegir tema y modo
4. Generar HTML
5. Presentar con app HTMLSlides
