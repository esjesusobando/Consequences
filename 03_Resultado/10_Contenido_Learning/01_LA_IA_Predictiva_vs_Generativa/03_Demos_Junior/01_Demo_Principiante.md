# Demo Junior: IA Predictiva vs Generativa

## Demo 1: Identificar el Problema

**Pregunta clave**: ¿Tu problema es CREAR algo o PREDECIR algo?

| Si tu respuesta es... | Entonces necesitas... |
|----------------------|----------------------|
| "Quiero redactar emails" | IA Generativa |
| "Quiero saber quién va a dejar mi servicio" | IA Predictiva |
| "Quiero crear imágenes" | IA Generativa |
| "Quiero predecir ventas del próximo mes" | IA Predictiva |
| "Quiero resumir documentos" | IA Generativa |
| "Quiero detectar fraude" | IA Predictiva |

---

## Demo 2: Comparación Práctica Simple

### IA Generativa (como un escritor creativo)
```
Input: "Escribe un email de respuesta a cliente quejó"
Output: Email redactado, profesional, persuasivo
```

### IA Predictiva (como un analista de datos)
```
Input: Datos históricos de clientes + intención de abandono
Output: "Este cliente tiene 87% probabilidad de abandonar"
```

## Demo 3: Caso Combinado Real

**Problema**: Empresa de SaaS con 10% churn mensual

**Solución con AMBOS tipos de IA**:

1. **Predictiva**: Modelo detecta clientes con alto riesgo de churn
2. **Generativa**: Chatbot genera mensaje personalizado para cada cliente

```
CLIENTE #4827:
- Predictiva dice: 89% probabilidad de abandono
- Generativa genera: "Hola María, notamos que no has usado 
  la última función de reportes. ¿Necesitas ayuda para 
  implementarla? Tenemos un tutorial de 5 minutos..."
```

## Demo 4: Herramienta Sin Código

### Para IA Generativa:
- ChatGPT / Claude → Escribir, resumir, crear

### Para IA Predictiva:
- Google Sheets → Función FORECAST()
- Airtable → Automations con lógica
- Notion → Fórmulas condicionales

**Empezar gratis**: Prueba FORECAST() en Sheets con tus datos de ventas.
