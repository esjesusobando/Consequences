# App Oil - Centro de Mando para Ingeniería de Pozos

**Oil** es una plataforma integral diseñada para centralizar cálculos, documentación y mejores prácticas en las áreas de Perforación y Rehabilitación de pozos petroleros. Este repositorio sirve como el centro de mando y contexto técnico para el desarrollo de tareas y proyectos relacionados con la industria del petróleo y gas.

## Áreas de Especialidad y Referencias

A continuación se presentan las referencias clave, incluyendo manuales técnicos, libros, normas y laboratorios para cada una de las 10 áreas fundamentales.
