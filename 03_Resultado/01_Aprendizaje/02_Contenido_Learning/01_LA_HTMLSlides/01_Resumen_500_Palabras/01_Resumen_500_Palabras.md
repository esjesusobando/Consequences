# Resumen: HTMLSlides - PowerPoint Killer con IA

## Resumen (Español)
Jay E (RoboNuggets) presenta HTMLSlides, una herramienta que convierte Claude Code (o cualquier AI agent) en un creador de presentaciones profesional.

**El problema que resuelve**: PowerPoint es lento y feo. Gamma es caro. HTML Slides ofrece alternativa gratis, open source, local-first.

**Cómo funciona**:
1. Instalas la skill desde GitHub (30 segundos)
2. Describes qué quieres en inglés
3. La skill genera HTML con 17 temas visuales
4. Presentas con app dual-display (presentador + audiencia)

**Dos modos**:
- **Pro Mode**: Componentes estructurados interactivos (charts, flip cards, timelines, stats)
- **Vibe Mode**: Temas creativos con IA interpretando libremente el contenido

**Ventajas sobre alternativas**:
- Single HTML file (sin dependencias, sin build step)
- Local-first, sin cuenta, sin suscripción
- Convierte PPT, reveal.js, Marp, Google Slides
- Speaker notes generados por IA
- Dual-display sync en tiempo real

**Instalación**: `claude plugin marketplace add bluedusk/html-slides`

## Resumen (English)
Jay E (RoboNuggets) presents HTMLSlides, a tool that turns Claude Code (or any AI agent) into a professional presentation creator.

**The problem it solves**: PowerPoint is slow and ugly. Gamma is expensive. HTML Slides offers a free, open source, local-first alternative.

**How it works**:
1. Install skill from GitHub (30 seconds)
2. Describe what you want in English
3. Skill generates HTML with 17 visual themes
4. Present with dual-display app (speaker + audience views)

**Two modes**:
- **Pro Mode**: Structured interactive components (charts, flip cards, timelines, stats)
- **Vibe Mode**: Creative themes with AI freely interpreting content

**Advantages over alternatives**:
- Single HTML file (no dependencies, no build step)
- Local-first, no account, no subscription
- Converts PPT, reveal.js, Marp, Google Slides
- AI-generated speaker notes
- Real-time dual-display sync

**Installation**: `claude plugin marketplace add bluedusk/html-slides`
