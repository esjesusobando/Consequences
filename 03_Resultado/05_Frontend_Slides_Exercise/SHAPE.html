Deep Learning Slide 06 / 25

CAPAS PROFUNDAS,
MAYOR
ABSTRACCIÓN

Las redes neuronales profundas apilan capas para construir representaciones cada vez más abstractas de los datos.

Cada capa transforma la salida de la anterior. Las primeras capas detectan bordes y texturas; las últimas reconocen conceptos complejos como "gato" o "conversación".

Feature hierarchy: jerarquía de representaciones aprendidas
Gradient flow: backpropagation atraviesa todas las capas
Transfer learning: capas pre-entrenadas reutilizables

RAG Systems Slide 08 / 25

RETRIEVE +
GENERATE =
RAG

Retrieval-Augmented Generation combina búsqueda de documentos con generación de texto para respuestas basadas en evidencia.

El modelo primero recupera chunks relevantes de tu base de conocimiento, luego genera respuestas citando fuentes específicas.

Vector search encuentra documentos semánticamente similares
Context window del modelo limita la cantidad de chunks
Grounded responses reducen alucinaciones significativamente

Prompt Engineering Slide 11 / 25

INSTRUYE AL
MODELO CON
PRECISIÓN

La forma en que escribes el prompt impacta directamente la calidad de las respuestas.few-shot vs zero-shot vs chain-of-thought.

Un buen prompt incluye: contexto, ejemplos, formato de salida y restricciones. Iterar sobre el prompt es más barato que re-entrenar.

Clear instructions: qué quieres y cómo lo quieres
Role assignment: "eres un experto en..."
Output formatting: JSON, markdown, bullet points

Learning Modes Slide 13 / 25

ZERO-SHOT
VS
FEW-SHOT

Zero-shot: sin ejemplos, el modelo infiere de la instrucción. Few-shot: con 2-5 ejemplos, el modelo aprende el patrón.

Zero-shot es más rápido y flexible. Few-shot funciona mejor para tareas complejas o con formatos específicos.

Zero-shot: "Clasifica este review como positivo/negativo"
Few-shot: 3 ejemplos de reviews + respuestas correctas
K-shot: balance entre ejemplos y context window
