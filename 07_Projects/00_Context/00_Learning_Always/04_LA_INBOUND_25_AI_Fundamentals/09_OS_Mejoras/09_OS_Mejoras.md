## Mejoras Identificadas

### 1. Custom Instructions en AI Principal

**Qué**: Configurar tu AI principal con instrucciones custom

**Cómo**:
```
Settings → Custom Instructions
→ "Soy [tu rol] trabajo en [tu campo]
→ Escribo en estilo [estilo]
→ Se enfocan en [objetivo]
```

**Impacto**: 10 min → mejores resultados para siempre

**Estado**: ⏳ Pendiente

### 3. Framework TRIAGE en Workflow

**Qué**: Aplicar la estrategia a tu trabajo

```
TRIAGE → Prioriza por frecuencia × impacto
EXPERIMENT → Prueba con prompts
AUTOMATE → Build agente cuando funcione
MEASURE → Mide con KPIs
```

**Integración**: Agregar a tu weekly review

**Estado**: ⏳ Pendiente

---

### 4. Meta Prompting Workflow

**Qué**: Agregar step de mejora de prompts

**Cuándo**: Cuando un prompt funciona bien

**Cómo**:
```
1. Usar el prompt exitosamente
2. "Mejora este prompt"
3. Guardar versión mejorada
4. Usar la versión mejora en adelante
```

**Estado**: ⏳ Pendiente

---

### 5. Documentación de Casos de Uso

**Qué**: Keep track de cómo usás AI

**Template**:
```
## Caso de Uso: [nombre]
- Cuándo usarlo: [trigger]
- Prompt: [prompt]
- Contexto necesario: [context]
- Resultado esperado: [output]
- Métrica: [KPI]
```
