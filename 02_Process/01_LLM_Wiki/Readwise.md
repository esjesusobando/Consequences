# Readwise

## Overview
Servicio de captura de highlights de redes sociales, artículos, y otros contenidos. Integra con Obsidian para centralizar notas.

## Key Features
- **Capture**: Guarda highlights de Twitter, artículos, YouTube, etc.
- **Integration**: Sincroniza con Obsidian, Notion, Logseq
- **Organization**: Tags, collections, search
- **Review**: Daily review de highlights guardados

## Use Case in AI Research OS
- Fuente de contenido para el second brain
- Highlights de artículos y redes sociales
- Se integra con el deep research algorithm
- Contribuye al index.yaml del wiki

## Setup
- Instalar extensión de navegador
- Conectar con Obsidian (plugin o CLI)
- Configurar auto-import de highlights
